3. Теоретичні розрахунки та лістинг


3.1. Аналітичний розрахунок ДПФ

Обчислення виконується за базовою формулою дискретного перетворення Фур’є, де значення ДПФ масштабується на крок дискретизації \(T_{a}\) для відповідності неперервному аналогу:
\(F(j\omega _{k})=T_{a}\cdot F_{d}(j\omega _{k})=T_{a}\cdot \sum _{n=0}^{N-1}f(nT_{a})e^{-j\omega _{k}nT_{a}}\)
Для кожної дискретної частоти \(\omega_k = \frac{2\pi}{N T_a} k\) розраховується модуль комплексної величини через суму косинусних та синусних компонент:
\(|{}F(j\omega _{k})|{}=T_{a}\cdot \sqrt{\left(\sum _{n=0}^{9}f(nT_{a})\cos (\omega _{k}nT_{a})\right)^{2}+\left(\sum _{n=0}^{9}f(nT_{a})\sin (\omega _{k}nT_{a})\right)^{2}}\)
Результати аналітичного обчислення амплітуд спектральних ліній \(\vert{}F(j\omega_k)\vert{}\):
• \(k = 1\) (\(\omega_1 = 2\pi\)): \(\vert{}F(j\omega_1)\vert{} = 2.20\)
• \(k = 2\) (\(\omega_2 = 4\pi\)): \(\vert{}F(j\omega_2)\vert{} = 1.86\)
• \(k = 3\) (\(\omega_3 = 6\pi\)): \(\vert{}F(j\omega_3)\vert{} = 1.43\)
• \(k = 4\) (\(\omega_4 = 8\pi\)): \(\vert{}F(j\omega_4)\vert{} = 0.62\)
• \(k = 5\) (\(\omega_5 = 10\pi\)): \(\vert{}F(j\omega_5)\vert{} = 1.61\)
• \(k = 6\) (\(\omega_6 = 12\pi\)): \(\vert{}F(j\omega_6)\vert{} = 0.70\)
• \(k = 7\) (\(\omega_7 = 14\pi\)): \(\vert{}F(j\omega_7)\vert{} = 0.61\)
• \(k = 8\) (\(\omega_8 = 16\pi\)): \(\vert{}F(j\omega_8)\vert{} = 1.91\)
• \(k = 9\) (\(\omega_9 = 18\pi\)): \(\vert{}F(j\omega_9)\vert{} = 2.16\)
• \(k = 10\) (\(\omega_{10} = 20\pi\)): \(\vert{}F(j\omega_{10})\vert{} = 1.29\)


4. Графік результатів

Візуалізація амплітудного спектра із нульовою частотою в центрі (вісь частот симетрично відображає від'ємні та додатні спектральні компоненти в межах частоти Найквіста від \(-5\) Гц до \(5\) Гц).

5. Відповіді на контрольні запитання (стисло)

1. Як записується ряд Фур’є у комплексній формі?
У комплексній формі ряд Фур'є для періодичної функції \(f(t)\) записується як:
\(f(t)=\sum _{n=-\infty }^{\infty }c_{n}e^{jn\omega _{0}t}\)
де \(c_{n}\) — комплексні амплітуди (коефіцієнти розкладу).
2. Дати визначення тотожності Парсеваля.
Тотожність Парсеваля стверджує, що повна енергія сигналу, розрахована в часовій області, дорівнює сукупній енергії його спектральних компонент у частотній області: \(\frac{1}{2\pi} \int_{0}^{2\pi} \vert{}f(t)\vert{}^2 dt = \sum_{n=-\infty}^{\infty} \vert{}c_n\vert{}^2\).
3. Що таке спектральна густина?
Це комплексна функція частоти \(F(j\omega)\), що описує безперервний частотний спектр неперіодичного сигналу та визначає щільність розподілу амплітуд і фаз за частотною віссю.
4. Які перетворення є похідні від перетворення Фур’є?
До похідних належать косинусне та синусне перетворення Фур'є (для дійсних сигналів), а також перетворення Хартлі, яке використовує симетричні дійсні базові функції \([\cos(\omega t) + \sin(\omega t)]\).
5. У чому принципова відмінність спектрів дискретного і аналогового сигналів?
Спектр аналогового (неперіодичного) сигналу є суцільним та зазвичай затухаючим. Спектр дискретизованого сигналу завжди є строго періодичним на осі частот із періодом, який дорівнює частоті дискретизації \(f_{a}\).
